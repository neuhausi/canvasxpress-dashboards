Enrichment Analysis (over-representation)

A selected gene set scored for over-representation against five pathways with the hypergeometric test and Benjamini–Hochberg FDR. Bars are −log10 FDR; the pathway the query was drawn from rises to the top. The p-values match R's phyper / p.adjust.
