Pins Board Overview →

Real data, straight from a pins board. The Palmer Penguins dataset (344 measurements) is published to a Posit pins board and read back with board_url() over HTTP, then reshaped into five species-tagged datasets. A Species filter drives three ring-card meters (count, body mass, flipper), an island bar, and a bill-shape scatter.

Pins Board (live connector) →

Read a pins board live, through the connector. The Palmer Penguins table is published to a Posit pins board with pin_write() and read back live via the real PinsBoardSource connector — nothing baked. Two species-colored scatters and a Species filter, driven off the live source. Point it at your own Connect / folder / S3 / URL board. (Sign in required.)

Automated Demo →

One authored storyboard, two ways to play. Press Play demo and a synthetic human drives the real UI — a ghost cursor glides across the dashboard dispatching genuine clicks, filter selections and per-panel chart actions (great for screen recordings). The same script compiles into the state-based Storyboard bar, which replays each step as live dashboard state. Reuses the engine's committed playDemo driver.

File-Drop Demo →

Rebind a panel by dropping a data file on it — driven automatically. A real desktop→browser file drag can’t be synthesized, so the driver builds the File in JS, puts it on a DataTransfer, and dispatches the genuine dragenter → dragover → drop while a labelled file-ghost glides onto the panel. A genuine import, no fake OS window.
