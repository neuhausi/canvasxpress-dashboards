CanvasXpress Dashboards

Compose, coordinate, and render dashboards — collections of linked CanvasXpress visualizations — from a single declarative JSON spec. See the repository README for the library API.

Quality Metrics →

Manufacturing quality board: four ring meters (three averages — yield, defect rate, on-time — plus a total inspection count) over 500 inspection records, a 500-point yield run chart per line, and a 500-bar defect-rate chart. Line and Shift controls filter every panel.

Biomarker Cohort →

60-sample immuno-oncology study: two boxplots with individual samples overlaid (IL-6 by group, TNF-α by response), an IL-6 vs TNF-α scatter, and a 24-gene inflammation heatmap. Treatment-group and response filter controls drive every panel.

Scientific board over six RNA-seq datasets (>1,000 records each): a clustered expression heatmap, a differential-expression volcano, MA and two-contrast scatters, a 1,600-cell single-cell UMAP, a sample-count ring meter, a response-by-stage stacked bar, and a Kaplan-Meier survival curve.
