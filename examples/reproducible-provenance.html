Reproducible Provenance

Each chart carries an auto-derived method line as a figure footer — read off what the panel actually computed (here: an aggregate pushdown, and a plain time-series line). The button below exports a reproducible bundle: a zip with the self-contained spec, a data snapshot, per-panel R & Python regeneration code, a methods.md, and a manifest.json carrying a content hash so a reviewer can tell two figures apart.
