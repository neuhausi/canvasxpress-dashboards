ggplot Gallery

Four charts authored in R with ggplot2 — a scatter, a boxplot, a bar chart and a time series. Each was converted once from its ggplot code via the canvasXpress R package's ggplot.as.list() and is rendered here as a native, interactive CanvasXpress panel (hover, selection, the customizer), not a static image. Built with the cxd-ggplot tool from a folder of R snippets.
