Dose–Response Lab

A mock early-phase trial (96 patients, four dose arms, 480 lab visits) where three of the four charts are computed on the server by data functions: an R nls() Emax dose–response fit and two Python pandas summaries. Click </> Code on a chart to see the exact code and the CanvasXpress config behind it. Needs a server with data functions enabled (CXD_FUNCTIONS) and a signed-in user.
