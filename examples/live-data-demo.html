Live-data controls — parameters re-query the source

This page injects a fake connector backend via options.fetch that reads the query string, so every control below actually re-queries and the bound panels refresh — no real database. In production the same spec omits options.fetch and talks to canvasxpress-connectors or the cxd_server dataset API over a cookie-authenticated endpoint.

Try: the Region dropdown (choices themselves come from a optionsFrom query) · the Search box (debounced, filters products by name) · click a bar in “Revenue by region” to cross-filter every panel to that region · watch the brief Loading… overlay as each query runs.
