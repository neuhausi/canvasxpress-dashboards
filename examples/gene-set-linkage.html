Gene-Set Linkage (selection)

Select one or more genes in the expression heatmap (click the gene row labels) and the same genes highlight in the differential-expression scatter — a cross-source gene set keyed gene-to-gene across panels. This marked set is what a downstream enrichment panel would consume.
