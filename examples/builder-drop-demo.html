File-Drop Demo

You can drop a data file in two places: on the Data page (the app’s import pane) or on any visualization — dropping on a panel rebinds it to the dropped dataset. This standalone Builder shows the second: the driver drops a CSV onto the panel below. A real desktop→browser file drag can’t be synthesized (it starts outside the page) — so the driver does what the drop handler actually reads: it builds the File in JavaScript, puts it on a DataTransfer, and dispatches dragenter → dragover → drop. For the video it glides a labelled file-ghost from the page edge onto the target (no fake OS window — that would read as fake). This is a genuine import, not a mock. In the full app, pass { dropFile: { …, onto: 'data' } } to target the Data page instead.
