Parquet Explorer (DuckDB pushdown)

A 300,000-row Parquet file read through a ParquetSource (DuckDB). Every panel is a grouped / filtered pushdown query, so DuckDB does the aggregation and only a handful of rows reach the browser. Run the adapter (python3 examples/parquet-adapter.py, after python3 examples/gen-parquet.py) for live data.
